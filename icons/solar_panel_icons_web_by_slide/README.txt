SOLAR PANEL WEB - TRANSPARENT ILLUSTRATION ICONS

This package contains 78 transparent PNG illustration icons used in the
24-slide Solar Panel presentation.

Folder mapping:
- slide_01 and slide_02 intentionally have no separate illustration icons.
- slide_03 through slide_24 contain the icons for their corresponding slides.
- icon_01.png, icon_02.png, and so on follow the content order from top to
  bottom on each slide.

Web usage:
- Keep the directory structure unchanged.
- Copy this folder into the web project's public assets directory.
- Use the exact PNG files; do not replace them with Lucide, Font Awesome,
  emoji, CSS line icons, or newly generated icons.
- Render with object-fit: contain and preserve the transparent background.
- Use the PDF as the visual reference for each icon's size and position.
